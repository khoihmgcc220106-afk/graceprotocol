# Grace Protocol

An industrial-grade diagnostic tool for regional phonological errors in Vietnamese, built with a robust Monorepo architecture.

## 🏗 Architecture & Tech Stack
* **Backend:** FastAPI, PostgreSQL 16, SQLAlchemy, Alembic (Python).
* **Frontend:** Next.js 16, App Router, Tailwind CSS, TypeScript.
* **Infrastructure:** Docker Compose, Pre-commit hooks.
